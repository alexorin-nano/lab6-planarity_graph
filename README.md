# lab6-planarity_graph

### `planarity.py` — проверка планарности и геометрическая укладка

Скрипт проверяет, является ли заданный граф планарным, с помощью
алгоритма комбинаторной укладки (Left-Right Planarity Test, реализован
в `networkx.check_planarity`). Если граф планарен, скрипт строит
геометрическую укладку без пересечений рёбер и сохраняет её в PNG-файл.

**Что делает программа по шагам:**

1. Задаёт граф `G` (в примере — «домик»: квадрат `A-B-C-D` с крышей `A-E-B`).
2. Вызывает `nx.check_planarity(G)`, которая возвращает:
   - `is_planar` — булево значение, планарен ли граф;
   - `embedding` — комбинаторную укладку (`PlanarEmbedding`), то есть
     циклический порядок соседей вокруг каждой вершины. Это и есть
     результат работы алгоритма комбинаторной укладки.
3. Если граф планарен:
   - выводит в консоль комбинаторную укладку (порядок соседей для каждой вершины);
   - строит геометрические координаты вершин через `nx.planar_layout(G)`
     так, чтобы рёбра не пересекались;
   - рисует граф и сохраняет картинку в `planar_drawing.png`.
4. Если граф не планарен — сообщает об это

### `planar_drawing.png` — геометрическая укладка планарного графа

Изображение содержит планарную (плоскую) укладку графа,
построенную функцией `nx.planar_layout` на основе комбинаторной укладки,
полученной алгоритмом проверки планарности.
